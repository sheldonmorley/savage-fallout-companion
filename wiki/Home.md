# Savage Fallout Companion

A fan-made conversion that brings Fallout to **Savage Worlds Adventure Edition (SWADE)**. It comes in two parts, and each works on its own:

| | **The book** | **The Foundry VTT module** |
|---|---|---|
| What it is | The complete game, as a PDF and a Google Docs file | The same game, ready to play in Foundry, with the bookkeeping automated |
| You need | SWADE | SWADE system and the SWADE Core Rules module, in Foundry v13 or v14 |
| Get it | [`docs/`](https://github.com/sheldonmorley/savage-fallout-companion/tree/main/docs) | Manifest: `https://raw.githubusercontent.com/sheldonmorley/savage-fallout-companion/main/module.json` |

The book is the game; the module is the game on autopilot. Nothing in the module changes the rules: everything it automates is written in the book.
